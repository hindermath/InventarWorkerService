# Regulatorische Anwendbarkeit / Regulatory Applicability

| Standard | Entscheidung / Decision | Annahme, Restrisiko und Trigger / Assumption, residual risk, trigger |
|---|---|---|
| NIST SSDF / CWE Top 25 | Applicable | immer für Level 2 / always for Level 2 |
| OWASP ASVS 5.0 L2 | Applicable | beide HTTP-Hosts / both HTTP hosts |
| NIS2 | N/A | kein als wesentlich/kritisch festgestellter Betreiber; Trigger Organisations-/Sektorentscheidung / no identified essential entity; trigger organisational/sector decision |
| DORA | N/A | kein Finanzunternehmen/ICT-Drittdienst im Scope; Trigger Vertrags-/Sektoränderung |
| EU AI Act | N/A | KI nur Entwicklungswerkzeug; Trigger KI-Runtime/Produkt |
| AI-SBOM | N/A | kein Modell, Dienst, Datensatz oder Inferenzsystem ausgeliefert; Trigger KI-Komponente |
| BSI C3A/C5 | N/A | keine Cloud-/Cloud-Assurance-Leistung; Trigger Cloudscope |

DE: Owner ist die Projektverantwortung, Reviewer Compliance/Security. Nichtanwendbarkeit wird bei jeder Scope-, Betreiber-, Vertrags-, Cloud- oder KI-Änderung neu geprüft.

EN: The project owner is accountable; compliance/security reviews. N/A is re-evaluated after any scope, operator, contract, cloud, or AI change.
