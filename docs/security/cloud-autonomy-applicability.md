# Cloud-Autonomie / Cloud Autonomy Applicability

DE: BSI C3A ist N/A, weil Feature 002 keinen Cloudprovider, Managed Service oder providerabhängiges Hosting einführt. Restrisiko ist spätere unbemerkte Providerbindung. Trigger ist SaaS, PaaS, IaaS, Managed Service oder Clouddeployment.

EN: BSI C3A is N/A because Feature 002 introduces no cloud provider, managed service, or provider-dependent hosting. Residual risk is later unnoticed provider lock-in. SaaS, PaaS, IaaS, managed service, or cloud deployment is the trigger.
